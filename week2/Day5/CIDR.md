Write the IP address 135.1.1.25 mask 255.255.248.0 in CIDR notation 
--> 

The binary subnet mask is: 11111111.11111111.11111000.00000000

The number of '1' bits in the binary subnet mask is 21.

The CIDR notation consists of the IP address followed by a slash and the number of '1' bits.

Therefore, CIDR notation is 135.1.1.25/21.
