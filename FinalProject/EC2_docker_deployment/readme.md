# Final Project: CI/CD Pipeline for Web Application Deployment on AWS & Kubernetes

This project demonstrates a complete CI/CD setup using Jenkins for building and deploying a containerized Flask web application on AWS infrastructure using Docker (on EC2). Infrastructure provisioning is done using Terraform with using concepts of modules.
